# RUNEGUARD

9x5 전장에서 **장군(General)** 을 직접 조종하며 카드로 병력을 소환하고,
**적 장군 격파** 또는 **중앙 아크(Ark) 점령** 으로 승리하는 1:1 전술 카드게임.

> 벤치마크: **Duelyst / Duelyst 2** (보드 전술) + **Hearthstone** (마나 곡선 · 영웅 능력 · 덱 구성)

---

## 실행

### 1. 그냥 열기 (가장 간단)
`index.html` 을 더블클릭하면 브라우저에서 바로 실행됩니다.
빌드 도구 · 의존성 · 설치 과정이 전혀 없습니다.

### 2. 개발 서버로 열기 (권장)
```bash
node tools/serve.js
```
`http://localhost:5173` 접속. 캐시가 꺼져 있어 코드를 고치면 새로고침만으로 반영됩니다.

## 검증 도구

### 규칙 단위 테스트
```bash
node tools/rules-test.js
```
이동 · 전투 · 반격 · 도발 · 오라 · 아크 · 승패 · 카드 데이터 정합성까지 42개 항목을 검사합니다.
**규칙을 손댈 때마다 반드시 먼저 돌려 보세요.**

### 밸런스 시뮬레이터
```bash
node tools/sim.js 25              # 4진영 라운드로빈 (12매치업 x 25판 = 300판)
node tools/sim.js 50 exile demon  # 특정 매치업만
```
진영별 승률 · 선공 승률 · 승리 사유 분포 · 카드 사용 빈도 · 거점 건설 빈도를 뽑아 줍니다.
AI 1수당 약 0.1~0.2ms 라서 300판이 10초 이내에 끝납니다.

### 카드 스탯 일괄 조정
```bash
node tools/tweak.js
```
`tools/tweak.js` 상단의 `TWEAKS` 배열을 고친 뒤 실행하면 `js/data.js` 의 스탯이 한 번에 바뀝니다.
`tweak → sim → rules-test` 순환이 밸런싱 기본 루프입니다.

## 파일 구조

```
runeguard/
├─ index.html            화면 뼈대
├─ css/style.css         전체 스타일 (다크 테마, 반응형)
├─ js/
│  ├─ data.js            카드 · 진영 · 상수  ← 밸런싱은 대부분 여기
│  ├─ art.js             부위 조립식 캐릭터 아트 (부위 46 · 전용도안 30)
│  ├─ audio.js           Web Audio 효과음 합성 (18종)
│  ├─ engine.js          규칙 엔진 (순수 데이터 상태, UI 비의존)
│  ├─ ai.js              AI 지휘관 (정적 평가 + 반격 위협)
│  ├─ net.js             온라인 친선전 (락스텝 프로토콜 + Supabase 중계)
│  ├─ builder.js         덱 빌더 (진영별 커스텀 덱, localStorage)
│  ├─ ui.js              렌더링 · 입력 처리 · 카드 도감
│  └─ main.js            부트스트랩
├─ tools/
│  ├─ serve.js           개발용 정적 서버
│  ├─ rules-test.js      규칙 단위 테스트
│  ├─ sim.js             밸런스 시뮬레이터
│  ├─ net-test.js        온라인 프로토콜 테스트 (가짜 회선 2인 대전)
│  └─ tweak.js           스탯 일괄 조정
└─ docs/design.md        기획서
```

**에셋 없는 설계** — 이미지 파일도 음원 파일도 없습니다.
그림은 `art.js` 가 SVG로 그리고, 소리는 `audio.js` 가 Web Audio 오실레이터로 그 자리에서 합성합니다.
덕분에 로딩도 네트워크 요청도 없고, 폴더째 올리면 어디서든 그대로 돕니다.

**부위 조립식 캐릭터** — 유닛은 아이콘이 아니라 **캐릭터**로 그립니다.
46종의 부위(다리·몸통·팔·머리·무기·방패·망토·날개)를 조합해 38종의 유닛을 만듭니다.

```
망토/날개 → 다리 → 몸통 → 팔·어깨 → 방패 → 무기 → 머리
```

덕분에 유닛 하나가 **48~64개 도형**으로 이루어지고, 전부 고유한 실루엣을 갖습니다.
탈것·건물·주문 30종은 전용 도안입니다.

**재질 팔레트** — 단색 틴트를 버렸습니다.
강철 · 어두운 강철 · 황금 · 가죽 · 피부 · 뼈 · 철 · 나무 · 석재를 각각 SVG 그라디언트로 정의하고,
**진영 색은 천 · 문장 · 마력에만** 들어갑니다. 같은 기사도 진영에 따라 망토 색이 달라집니다.

뒤에는 검은 실루엣을 한 겹 깔아 어두운 타일 위에서도 형태가 분리돼 보이게 합니다.

**설계 원칙** — `engine.js` 는 DOM을 전혀 모릅니다. 상태가 순수 데이터라서
AI가 복제 후 시뮬레이션할 수 있고, 브라우저 없이 Node에서 수백 판을 돌릴 수 있습니다.
이 구조 덕분에 밸런싱이 감이 아니라 숫자로 굴러갑니다.

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 보드 | 9열 x 5행. 장군은 좌우 중앙 (r2,c0) / (r2,c8). 아크는 정중앙 (r2,c4) |
| 승리 | 적 장군 격파 **또는** 아크를 점거한 채 자기 턴 시작 **4회** (적 병력이 인접하면 **경합** — 스택 일시 정지) |
| 마나 | 1에서 시작해 매 턴 +1, 상한 10. 턴 시작 시 전량 회복 |
| 덱 | 30장, 같은 카드 최대 2장. 선공 3장 / 후공 4장 + 「선제 보급」 |
| 유닛 | 턴당 **이동 1회 + 공격 1회**. 공격하면 그 턴 이동 종료 |
| 이동 | 직교로 기동력(mv)칸. `비행`은 넘어가고, `도약`은 L자 |
| 공격 | 사거리(rng) 는 체비셰프 거리. 제자리에서 때리고 전진하지 않음 |
| 반격 | **동시 교환** — 방어자가 죽어도 반격 피해가 들어간다. `선제공격`으로 죽이면 예외 |
| 소환 | 아군 유닛 · 장군 · 거점에 **인접한 빈 칸** |
| 영웅 능력 | 턴당 1회, 기본 2마나. 진영마다 다름 |
| 카드 교환 | 턴당 1회 무료 — 손패 1장을 덱과 교환 (멀리건 복구) |
| 거점 | 3마나, 자기 턴 기준 4턴마다 1개. 마나 첨탑 / 병영 / 전투 신단 |

키워드: `돌진` `질주` `도발` `방벽` `비행` `도약` `흡혈` `선제공격` `개시` `유언` `오라`

**영웅 킬 루트** — 카드의 단일 대상 피해(주문·개시)는 적 장군을 직접 지정할 수 있습니다.
광역 피해와 영웅 능력은 유닛 전용입니다 (무한 얼굴 번 방지).

## 카드 도감

시작 화면의 **카드 도감 보기** 또는 게임 중 **도감** 버튼으로 전체 65종을 볼 수 있습니다.
진영별 · 종류별(유닛/주문/장군·거점) 필터를 지원하고, 카드마다 스탯 · 키워드 · 효과 설명과
**어느 진영 기본 덱에 몇 장 들어가는지**까지 표시합니다. `ESC` 로 닫힙니다.

## 연출

전투가 눈에 보이게 만드는 요소들입니다. 전부 CSS 애니메이션이라 비용이 없습니다.

- **피해 숫자** — 맞은 칸 위로 떠오릅니다. 피해는 붉은 `−3`, 회복은 초록 `+2`
- **피격 흔들림 / 공격 돌진** — 때린 쪽은 앞으로 튀고, 맞은 쪽은 흔들리며 번쩍입니다
- **처치 폭발** — 파편 9개가 사방으로 흩어집니다
- **유닛 호흡** — 각자 다른 위상으로 위아래로 미세하게 움직입니다
- **아크 룬 회전** — 중앙 거점이 상시 회전하며 발광합니다
- **하이라이트 맥동** — 공격 가능 칸과 주문 대상이 깜빡입니다

연출은 스냅샷 비교로 만듭니다. 엔진을 건드리기 직전에 HP·위치를 찍어 두고
렌더가 끝난 뒤 차이를 계산해 이펙트를 얹습니다 — 그래서 **엔진은 연출을 전혀 모릅니다.**

`prefers-reduced-motion` 을 켠 사용자에게는 모든 애니메이션이 꺼집니다.

## 덱 빌딩 (v0.6)

메뉴의 **덱 빌딩** 버튼에서 진영별 커스텀 덱을 짭니다.
- 카드 풀 = 자기 진영 전 카드 + 중립 전 카드. 클릭해 넣고(최대 2장), 오른쪽 목록 클릭으로 뺍니다
- 정확히 30장이어야 저장되며, 브라우저(localStorage)에 진영별 1개씩 보관됩니다
- 저장해 두면 AI전·로컬 2인·온라인 친선전 모두 자동으로 내 덱을 씁니다
  (온라인은 핸드셰이크에 덱이 실려 가고, 조작된 덱은 상대 쪽에서 기본 덱으로 대체됩니다)

신규 카드 10종은 **기본 덱에 없고 덱 빌딩으로만** 넣을 수 있습니다:
척탄병 · 레일건 포대 (밴가드) / 기수 · 복수자 (엑자일) / 비전 기록자 · 폭풍 부름 (아케인) /
탐식귀 · 전쟁마귀 (데몬) / 결투가 · 바람 기수 (중립)

## 온라인 친선전 (v0.5)

메뉴에서 **온라인 친선전**을 고르고 내 진영을 선택한 뒤:
- **방 만들기** — 4자리 방 코드가 생성됩니다. 친구에게 알려주세요.
- **참가** — 받은 코드를 입력하면 자동으로 대국이 시작됩니다. (방장이 선공 P1)

동작 원리: 엔진이 시드 난수로 결정적이라, 양쪽이 같은 시드로 게임을 만들고
**행동만 주고받으면** 두 화면이 항상 같습니다(락스텝). 중계는 Supabase Realtime
브로드캐스트 채널 — DB에는 아무것도 저장되지 않습니다. 매 행동마다 상태 해시를
비교하고, 어긋나면(메시지 유실 등) 5초 주기 하트비트가 감지해 호스트 상태로
자동 재동기화합니다.

한계(친선전 수준): 매치메이킹·랭킹 없음, 개발자도구를 열면 상대 손패를 볼 수 있음
(양쪽 클라이언트가 전체 상태를 가지므로). 검증은 ── 접속 · 게임 생성 ──
  ✔ 양쪽 모두 게임 시작
  ✔ 역할 배정 — 호스트 P1 / 게스트 P2
  ✔ 진영 반영 — P1 엑자일, P2 데몬
  ✔ 같은 시드로 동일한 초기 상태
  ✔ 덱 순서까지 동일

── 락스텝 진행 (행동 중계) ──
  ✔ 한 판 완주 (299행동, 44턴)
  ✔ 전 행동 구간에서 상태 어긋남 없음
  ✔ 승자 판정 일치

── 안전장치 ──
  ✔ 자기 턴이 아닌 쪽의 행동은 무시된다
  ✔ 유실 직후 상태가 어긋난다 (교착 상황)
  ✔ 하트비트가 어긋남을 감지해 재동기화한다
  ✔ 게스트가 sync 이벤트를 받았다
  ✔ 복구 후 턴 정보도 일치 (교착 해소)

## 진영

| 진영 | 정체성 | 영웅 능력 |
|---|---|---|
| **밴가드** (장군: 사령관) | 소총 · 전차. 원거리 화력과 진지 구축 | 조준 사격 — 적 유닛에 2 피해 |

## 현재 밸런스 (AI 보통, 300판 기준)

| 지표 | 값 |
|---|---|
| 평균 게임 길이 | 29턴 |
| 선공 승률 | 57% |
| 승리 사유 | 장군 격파 56% / 아크 점령 44% |
| 진영 승률 | 밴가드 49% · 엑자일 47% · 아케인 43% · **데몬 60%** |

### 알려진 과제
- **데몬 승률 60%** — 아직 상향 평준화 필요. 체급 대비 자해 비용이 가볍다.
- **선공 승률 57%** — 「선제 보급」으로 68% → 57% 까지 내렸으나 여전히 유리하다.
- **마나 첨탑 · 전투 신단 채택률 저조** — AI가 누적 이득을 평가하지 못하는 한계.
  사람이 플레이할 때는 다를 수 있어, 실제 플레이 피드백이 필요하다.
- **카드 툴팁이 사이드 패널 전용** — 모바일에서는 호버가 없어 대체 UI가 필요하다.
- **일부 유닛이 같은 부위 조합을 쓴다** — 예: 소총병과 강습병은 무기가 같고 망토만 다르다.
  실루엣은 구분되지만 전용 부위를 더 만들면 좋다.
